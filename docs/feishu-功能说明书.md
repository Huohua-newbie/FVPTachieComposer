## 1. 这是什么

FVP 引擎角色立绘的查看与合成工具。浏览 `.bin` / HZC 资源里的 **角色 → 服装 → 动作**，
点表情差分即时合成，导出 PNG。Windows 桌面程序，**解压即用，用户不需要装 Python**。

## 3. 功能明细

> 每个功能固定五个字段，**不要增减字段**——字段一致才能横向比较，也才能被检索。

### F1 载入 BIN 资源

- **做什么**：解析 `.bin`，填充「角色 → 服装 → 动作」三级树，并生成各级缩略图
- **触发**：角色库标题栏「打开 BIN」／`Ctrl+O`／把 `.bin` 拖进窗口／拖到 exe 图标上启动
- **输入·输出**：一个 FVP `graph_bs.bin` → 左侧树 + 缩略图，右侧空态
- **边界**：不是 BIN 或已损坏 → 底部报错，可复制报错文本发给维护者
- **溯源**：引入 v2.0.0；拖入窗口自 v2.2.2

### F2 载入 HZC 文件夹

- **做什么**：递归扫描文件夹，按扩展名或 `hzc1` 文件头识别散装资源
- **触发**：角色库标题栏「打开 HZC 文件夹」／把文件夹拖进窗口
- **输入·输出**：一个文件夹 → 与 BIN 相同的三级树
- **边界**：文件夹里没有可识别资源 → 空树 + 提示，不崩溃
- **溯源**：引入 v2.1.0

### F3 三级树 + 缩略图

- **做什么**：角色 → 服装 → 动作逐级展开，每级带缩略图；动作名取 `CHR_角色_喜_制服` 里的「喜」
- **触发**：点击节点展开；单服装/单动作自动级联选中
- **输入·输出**：已载入的资源 → 可浏览的树
- **边界**：缩略图按需生成（展开到哪层解码哪层），大资源不会卡在载入
- **溯源**：缩略图自 v2.0.0；按需解码自 v2.1.x

### F4 底图舞台

- **做什么**：显示当前动作底图，支持滚轮缩放、拖拽平移、多帧翻页
- **触发**：点动作自动载入；`←` `→` 翻帧；`0` 复位缩放
- **输入·输出**：动作节点 → 可缩放平移的底图
- **边界**：单帧动作时 `←` `→` 无效但不报错
- **溯源**：缩放/平移自 v2.1.0

### F5 差分即时合成预览

- **做什么**：点任意一帧表情差分，右侧即时显示合成结果
- **触发**：点击差分缩略图
- **输入·输出**：底图 + 差分 → 合成图
- **边界**：合成失败 → 底部报错，保留上一次成功的结果
- **溯源**：v2.0.0 起

### F6 保存当前（`Ctrl+S`）

- **做什么**：把当前预览的这一张导出为 PNG
- **触发**：保存按钮／`Ctrl+S`
- **输入·输出**：当前合成图（或底图）→ 用户选定路径的 PNG
- **边界**：未选中任何帧时按钮不可用；路径无权限 → 报错不中断
- **溯源**：v2.0.0 起；成功提示改走状态栏自 v2.2.3

### F7 批量导出

- **做什么**：把当前底图的**全部差分帧**铺平导出为多张 PNG
- **触发**：批量导出按钮
- **输入·输出**：底图 + N 个差分 → N 张 PNG，按帧号命名
- **边界**：无差分时不导出空集，转入 F8 的兜底路径
- **溯源**：v2.0.0 起

### F8 无差分时导出底图

- **做什么**：非立绘文件夹、或该动作没有 `_表情` 变体时，右侧直接显示底图，保存/批量导出导的就是这张
- **触发**：与 F6 / F7 相同
- **输入·输出**：底图 → `..._base_帧号.png`
- **边界**：**不允许出现「能看不能导」**——看到的必须能导出
- **溯源**：v2.2.2 起

### F9 载出（`Ctrl+W`）

- **做什么**：清空当前资源，回到初始空状态，换资源不用重开程序
- **触发**：角色库标题栏「载出」／`Ctrl+W`
- **输入·输出**：当前会话 → 空态
- **边界**：有未保存改动时不弹确认框（导出是显式动作，不做脏检查）
- **溯源**：v2.2.2 起

### F10 主题切换（`L`）

- **做什么**：浅色 / 深色两套配色一键切换
- **触发**：窗口右上角图标／`L`
- **输入·输出**：主题状态 → 立即换色
- **边界**：切换后**当前浏览位置、选中帧、预览全部保留**
- **溯源**：v2.0.0 起

### F11 使用说明

- **做什么**：把操作步骤和快捷键放进程序内，用户不用回来看 README
- **触发**：窗口标题栏右上角「使用说明」图标
- **输入·输出**：无 → 模态对话框
- **边界**：`Esc` 关闭
- **溯源**：v2.2.2 起

### F12 成功提示（状态栏 + 提示音）

- **做什么**：保存/导出/载入/载出成功后，在**底部状态栏**显示结果并播一声柔和提示音，不弹浮层
- **触发**：上述操作成功
- **输入·输出**：操作结果 → 状态栏文字 + `winsound.MessageBeep`
- **边界**：失败仍走浮层常驻（可复制报错）；`FVP_SOUND=0` 可关提示音
- **溯源**：v2.2.3 起（此前是浮层横幅）

### F13 启动画面

- **做什么**：启动时显示浅色底 + 转圈 +「正在载入界面…」，载入完成 200ms 淡出
- **触发**：程序启动
- **输入·输出**：无 → 启动屏 → 主界面
- **边界**：**不允许出现「启动黑屏 → 界面亮」的跳变**
- **溯源**：v2.2.3 起

### F14 记住上次使用的文件夹

- **做什么**：打开/保存文件时默认落在上次用过的目录
- **触发**：任何文件对话框
- **输入·输出**：上次路径 → 本次默认路径
- **边界**：上次目录已不存在时回退到系统默认
- **溯源**：v2.2.2 起

### F15 异常日志落盘

- **做什么**：每次启动生成一个日志文件，记录版本号、Python 版本、打包态、平台、命令行与工作目录；运行中出现的异常一并写进同一个文件
- **触发**：程序启动自动开启，用户无需任何操作
- **输入·输出**：无 → `%LOCALAPPDATA%\FVPTachieComposer\logs\fvptachie-<版本>-<启动时刻>.log`
- **记录范围**
  - 未捕获异常：主线程、子线程（含缩略图线程池）、asyncio 任务
  - 界面事件回调里抛出的异常（flet 捕获后转成日志，用户看到的是它原有的崩溃页）
  - 我们自己 `try/except` 里吞掉、但属于预期外的异常（带完整栈）
  - 原生崩溃（段错误、栈溢出）：靠 `faulthandler` 写同一文件
  - 启动失败、界面初始化失败、正常退出各有一行标记，便于区分「崩了」和「关了」
- **边界（必须遵守）**
  - **界面上原有的提示一律不变**：错误文案、提示条、flet 崩溃页、打包后的崩溃弹窗都保持原样，日志只负责留证据
  - 只保留**最近 20 次**运行，不会无限堆积
  - 写日志失败（目录不可写等）时**静默降级**成只有控制台输出，绝不影响程序运行
  - 日志在本地，不上传任何地方；文件名带版本号，用户报错时能对上「哪一版哪一次」
- **溯源**：`d7aa675`（版本号唯一来源见 `fvpapp/version.py`）

## 4. 界面约定（不是功能，是约束）

改界面时按这些来，别凭感觉：

- 浅灰页底 + 白色细描边卡片；卡片**不用**纹理、渐变、阴影 —— 立绘是画面里唯一该抢眼的东西
- 三级层级靠**位置 + 导轨线**读出来，不靠字号大小
- 舞台是透明棋盘底，避免立绘空隙和纯白混淆；预览溢出裁在自己的圆角框内
- 只有中间底图舞台随窗口伸缩；角色树与合成结果固定宽度 —— 拉窄窗口挤压的是预览区，不是列表
- 滚动条单独留槽，滑块不占内容
- 选中、展开、拖放都要有过渡，反馈看得见但不抢注意力
