# FVP Tachie Composer v2.1.1-beta

FVP 引擎角色立绘查看与合成工具——**即开即用**，无需安装 Python。

## 使用方法

1. 解压下载的 `FVPTachieComposer-v2.1.1-beta-win64.zip`
2. 双击 `FVPTachieComposer.exe` 运行
3. 点击左上角 **文件夹图标**，选择 FVP 引擎的 `.bin` 资源文件
4. 左侧按 **角色 → 服装 → 动作** 展开浏览（每级均有缩略图预览）
5. 点击动作自动加载底图，底部显示差分表情帧
6. 点击差分缩略图即时合成，右侧实时预览
7. 点击 **保存** 导出当前合成图，或点击 **批量导出** 导出全部差分帧

## 功能亮点

- **三级目录**：角色 → 服装 → 动作，每级带缩略图
- **语义动作名**：自动提取 `CHR_角色_喜_制服` 中的「喜」
- **即时合成**：点击差分即时预览合成结果
- **批量导出**：一键导出某动作全部差分帧，失败不中断
- **主题切换**：深色/浅色一键切换
- **单文件运行**：无需 Python 环境，解压即用

## 系统要求

- Windows 10/11 64-bit
- 无需安装 Python 或任何依赖
