# FVP Tachie Composer

FVP 引擎角色立绘查看与合成工具：浏览 `.bin` / HZC 资源里的 角色 → 服装 → 动作，
点击表情差分即时合成，导出 PNG。**解压即用**，无需安装 Python。

## 下载

到 [Releases 页面](https://github.com/Huohua-newbie/FVPTachieComposer/releases/latest)
下载 `FVPTachieComposer-<版本>-win64-flet.zip`。

发布页会附带 `SHA256SUMS.txt`，解压前可对一下哈希：

```powershell
(Get-FileHash .\<下载的文件名>.zip -Algorithm SHA256).Hash.ToLower()
```

## 使用方法

1. **解压整个目录**（产物是 `exe` + 数据目录，不是单个文件），双击 `FVPTachieComposer.exe`
2. 载入资源，任选一种：
   - 把 `.bin` 或 HZC 文件夹**直接拖进程序窗口**
   - 点左侧「角色库」标题栏的 **打开 BIN** / **打开 HZC 文件夹** 图标（或按 `Ctrl+O`）
   - 把文件拖到 `FVPTachieComposer.exe` 图标上，启动即载入
3. 左侧按 **角色 → 服装 → 动作** 三级展开浏览，每级都有缩略图
4. 点击动作自动加载底图：滚轮缩放、拖拽平移，多帧底图用 `←` `→` 翻帧
5. 点击差分缩略图即时合成，右侧实时预览
6. **保存当前** 导出这一张 PNG，**批量导出** 把该底图的全部差分帧铺平
7. 换资源时点「角色库」标题栏的 **载出**（`Ctrl+W`）回到初始空状态，不用重开程序

忘了键位就点窗口标题栏右上角的 **使用说明** 图标，操作步骤和快捷键都在里面。

> 这张立绘没有表情差分时（例如载入的是非立绘文件夹，或该动作压根没有 `_表情` 变体），
> 右侧会直接显示当前底图帧，**保存 / 批量导出导的就是这张底图**，文件名用 `..._base_帧号.png`。
> 也就是说：看到的就能导出来，不会只让你看。

### 快捷键

| 键位 | 作用 |
| --- | --- |
| `←` `→` | 上一帧 / 下一帧 |
| `0` | 复位缩放 |
| `Ctrl+O` | 打开 BIN |
| `Ctrl+S` | 保存当前（合成图或底图） |
| `Ctrl+W` | 载出，回到初始状态 |
| `L` | 切换深浅主题 |
| `Esc` | 关闭对话框 |

## 能做什么

- **浏览**：角色 → 服装 → 动作三级展开，每级带缩略图；动作名直接从 `CHR_角色_喜_制服` 里取「喜」
- **查看**：底图舞台支持滚轮缩放、拖拽平移，多帧底图翻帧查看
- **合成**：点任意一帧表情差分，右侧即时看到合成结果
- **导出**：保存当前这一张，或批量导出该底图的全部差分帧铺平成 PNG
- **没有表情差分时直接导出底图**：非立绘文件夹、或该动作压根没有 `_表情` 变体，
  右侧显示的就是可导出的底图，导出的也就是你看到的这一张
- **载入**：把 `.bin` / HZC 文件夹拖进窗口，或点「角色库」标题栏的图标，或把文件拖到 exe 图标上启动即载入
- **载出**：一键回到初始状态，换资源不用重开程序
- **主题**：深浅两套配色一键切换（窗口标题栏右上角图标或按 `L`），当前浏览、选中的帧与预览全部保留
- **成功提示走状态栏**：保存 / 导出 / 载入 / 载出成功后，底部状态栏显示结果并播一声轻提示音，不弹浮层打断操作（设 `FVP_SOUND=0` 可关掉声音）
- **启动即见画面**：启动时先显示浅色底 +「正在载入界面…」，不会出现「黑屏一下再突然亮起来」
- **记住上次的文件夹**：打开和保存对话框各自记住上次用过的目录，下次直接落在那里
- **记住窗口**：窗口的大小、位置和最大化状态都按上次关掉程序时的样子还原，拖动/缩放之后不用等退出就记上了。偏好存在 `%LOCALAPPDATA%\FVPTachieComposer\settings.json`；删掉它，或者上次记下的坐标已经落在当前屏幕外（拔掉一块显示器），就回默认 1280×760

## 界面

- 浅灰页底 + 白色细描边卡片，卡片不用纹理、渐变和阴影——立绘本身是画面里唯一该抢眼的东西
- 动作层比服装层再往右退一级并挂导轨线，三级层级靠位置和一条线读出来，不靠字号
- 舞台是透明棋盘底，立绘的空隙不会和纯白混淆；预览溢出被裁在自己的圆角框内
- 三栏里只有中间底图舞台随窗口宽度伸缩，角色树与合成结果都是固定宽度——拉窄窗口挤压的是预览区，不是列表
- 列表为滚动条单独留槽，滑块不占内容
- 选中、展开、拖放都有过渡，反馈看得见但不抢注意力

## 系统要求

- Windows 10 / 11 64-bit
- 无需安装 Python 或其他任何依赖

## 出问题了怎么反馈

程序会把异常写进日志文件，报 bug 时**把这个文件一起附上**，比描述半天管用：

```
%LOCALAPPDATA%\FVPTachieComposer\logs\
```

- 一次运行一个文件，文件名带版本号和启动时间（例如 `fvptachie-2.2.3-20261027-153012.log`）
- 里面是版本、系统信息、调用栈；**不含你的立绘资源**
- 只保留最近 20 次，不会越堆越多
- 界面上原本的错误提示不会因为日志而改变 —— 日志只是多留一份证据
