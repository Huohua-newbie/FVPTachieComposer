# FVP Tachie Composer

FVP 引擎角色立绘查看与合成工具，支持浏览、预览、合成和批量导出角色立绘差分部件。

## 功能

- 打开 FVP 引擎的 `.bin` 资源文件，自动解析所有角色立绘数据
- **三级目录浏览**：角色 → 服装 → 动作，每级均有缩略图预览
- 点击动作自动加载底图，底部展示该动作所有差分表情帧缩略图
- 点击差分缩略图即时合成预览，右侧显示合成结果
- 逐帧浏览多帧底图动画
- 保存单张合成图为 PNG
- 批量导出某个动作的全部差分帧
- 深色 / 浅色主题切换
- 自定义标题栏，支持最小化、最大化、关闭

## 使用方法

### 1. 安装依赖

需要 Python 3.10 或更高版本。

```bash
pip install -r requirements.txt
```

依赖项：`flet[desktop]>=0.86.5`、`Pillow>=10.3.0`

### 2. 启动程序

```bash
python FVPTachieComposerFlet.py
```

### 3. 操作步骤

1. 点击左上角 **文件夹图标** 或标题栏的「打开 BIN」按钮，选择 FVP 引擎的 `.bin` 资源文件
2. 左侧角色库以三级树形结构展示所有角色数据：
   - **第一级**：角色名（带头像缩略图）
   - **第二级**：服装分类
   - **第三级**：具体动作（带缩略图）
3. 点击某个动作，中间区域加载该动作的底图
4. 底部显示该动作对应的差分表情部件，点击任意缩略图即可合成
5. 右侧实时显示合成结果
6. 点击 **保存按钮** 将当前合成图保存为 PNG
7. 点击 **批量导出按钮** 选择文件夹，导出该动作全部差分帧

### 4. 其他操作

- **帧导航**：多帧底图可通过左右箭头逐帧切换
- **主题切换**：点击标题栏月亮/太阳图标切换深色和浅色主题
- **快捷键**：底部差分列表支持 Shift + 滚轮横向滚动，或直接拖拽滚动条

## 技术栈

- **Flet** — 基于 Flutter 的 Python UI 框架，Material Design 3 风格
- **Pillow** — 图像处理，负责立绘部件的解码、缩放与合成
- **FVPTachieComposer 核心逻辑** — BIN 文件解析、HZC 图像解码、立绘合成
