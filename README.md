# FVP Tachie Composer v2.2.1-beta

FVP 引擎角色立绘查看与合成工具——**即开即用**，无需安装 Python。

## 使用方法

1. 解压下载的 `FVPTachieComposer-v2.2.1-beta-win64.zip`
2. 双击 `FVPTachieComposer.exe` 运行
3. 点击左上角 **文件夹图标**，选择 FVP 引擎的 `.bin` 资源文件
4. 左侧按 **角色 → 服装 → 动作** 展开浏览（每级均有缩略图预览），顶部搜索框可按任意层级名字过滤
5. 点击动作自动加载底图：滚轮缩放、拖拽平移，下方滑块擦洗帧，`▶` 可自动播放
6. 点击差分缩略图即时合成，右侧实时预览；**对位微调** 的 X/Y 滑杆用于修正差分与底图的错位
7. 点击 **保存当前** 导出这一张 PNG，或点击 **批量导出** 把该动作全部差分帧铺平

### 快捷键

| 键位 | 作用 |
| --- | --- |
| `←` `→` | 上一帧 / 下一帧 |
| `[` `]` | 上一个 / 下一个差分部件 |
| `P` | 自动播放 / 暂停 |
| `0` | 复位缩放 |
| `Ctrl+S` | 保存当前合成图 |
| `Ctrl+O` | 打开 BIN |
| `L` | 切换深浅主题 |
| `Esc` | 清空搜索 / 关闭对话框 |

## 功能亮点

- **三级目录 + 搜索**：角色 → 服装 → 动作，每级带缩略图，几百张图也能一秒定位
- **语义动作名**：自动提取 `CHR_角色_喜_制服` 中的「喜」
- **透明棋盘舞台**：立绘的空隙不再与纯白混淆，预览溢出被裁在自己的圆角框内，不会糊到相邻区块
- **帧擦洗与自动播放**：多帧底图可以拖滑块逐帧看，也可以直接放一遍确认动画
- **对位微调**：差分偏移量可在界面上 ±48px 修正后再导出
- **即时合成**：点击差分即时预览合成结果
- **批量导出**：一键导出某动作全部差分帧，失败不中断
- **主题切换**：深色/浅色一键切换
- **单文件运行**：无需 Python 环境，解压即用

## 系统要求
