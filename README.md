# FVP Tachie Composer v2.2.2-beta

FVP 引擎角色立绘查看与合成工具——**解压即用**，无需安装 Python。

## 使用方法

1. 解压 `FVPTachieComposer-2.2.2-beta-win64-flet.zip`（产物是 `exe + 数据目录`，请解压整个目录），双击 `FVPTachieComposer.exe`
2. 载入资源，三选一：
   - 把 `.bin` 或 HZC 文件夹**直接拖进程序窗口**
   - 点角色库标题栏的 **打开 BIN** / **打开 HZC 文件夹** 图标
   - 按 `Ctrl+O` 选 `.bin`
3. 左侧按 **角色 → 服装 → 动作** 三级展开浏览，每级都有缩略图
4. 点击动作自动加载底图：滚轮缩放、拖拽平移，多帧底图用 `←` `→` 翻帧
5. 点击差分缩略图即时合成，右侧实时预览
6. **保存当前** 导出这一张 PNG，**批量导出** 把该底图的全部差分帧铺平
7. 换别的资源时点标题栏的 **载出**（`Ctrl+W`）回到初始空状态，不用重开程序

> 这张立绘没有表情差分时（例如载入的是非立绘文件夹，或该动作压根没有 `_表情` 变体），
> 右栏会直接镜像当前底图帧，**保存/批量导出走底图本身**，文件名用 `..._base_帧号.png`。
> 也就是说：看到的就能导出来，不会只让你看。

### 快捷键

| 键位 | 作用 |
| --- | --- |
| `←` `→` | 上一帧 / 下一帧 |
| `0` | 复位缩放 |
| `Ctrl+O` | 打开 BIN |
| `Ctrl+S` | 保存当前（合成图或底图） |
| `Ctrl+W` | 载出，回到初始状态 |
| `L` | 切换深浅主题 |
| `Esc` | 关闭对话框 |

## 功能亮点

- **拖进窗口即载入**：落点覆盖整扇窗口，边框会亮起行进光斑告诉你松手的位置；
  拖进来的是不支持的类型时给一次红框拒绝反馈，不会静默吞掉
- **三级目录**：角色 → 服装 → 动作，动作层再往右退一级并挂导轨线，层级一眼可读
- **语义动作名**：自动提取 `CHR_角色_喜_制服` 中的「喜」
- **克制的界面**：浅灰页底 + 白色细描边卡片，不用纹理、渐变和阴影——立绘本身是画面里唯一该抢眼的东西
- **透明棋盘舞台**：立绘的空隙不再与纯白混淆，预览溢出被裁在自己的圆角框内，不会糊到相邻区块
- **滚动条留槽**：列表为滚动条单独留了道槽，滑块贴在槽里，不再压着缩略图和按钮
- **即时合成**：点击差分即时预览合成结果，选中行与差分框带 180ms 过渡
- **换主题不丢现场**：展开的角色/服装、选中的动作与差分帧、底图和合成预览、
  标题栏的文件名全部保留，只换配色
- **导入/导出各记各的目录**：选完导出目录后，再开 bin 不会被带去导出那边
- **无差分也能导出**：见上面那条提示

## 系统要求

- Windows 10/11 64-bit
- 无需安装 Python 或任何依赖

## 校验

发布页附带 `SHA256SUMS.txt`。PowerShell 自查：

```powershell
(Get-FileHash .\FVPTachieComposer-2.2.2-beta-win64-flet.zip -Algorithm SHA256).Hash.ToLower()
```
